# animationsss — A pocket universe

An interactive glass planet around the original pink lilies. The flower SVG, flower colors, and original growth/sway choreography are preserved.

Live experience: https://joshmio42-cpu.github.io/animationsss/

Touch the three stars to discover three little notes. Finding all three reveals a heart constellation and the final dedication. “A little more magic” creates a meteor shower; “Start over” resets the secrets and blooms. Opens directly with no intro gate.

## Run locally

Open index.html directly or serve this folder with any static server. No build step, dependencies, tracking, or remote assets. FLORES.html opens the same experience.

## Files

- css/universe.css: glass planet, orbit, typography, and responsive layouts.
- js/universe.js: hidden notes, finale, reset, and lightweight canvas stardust.
- img/pink-lily.svg: unchanged pink lily artwork.
- css/main.css and css/lilies.css: original flower animation and pink palette.

Keyboard users can Tab to the three star buttons and activate them with Enter or Space. Revealed notes are announced through a live status region. Reduced-motion settings disable flower motion, animated heart drawing, and moving stardust. The canvas pauses in background tabs.
