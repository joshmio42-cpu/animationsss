# Pink Lilies

An all-pink adaptation of [gmpsankalpa/Flower-animation](https://github.com/gmpsankalpa/Flower-animation), retaining its growing garden and swaying stems.

The gift screen opens a bouquet of three six-petal pink lilies with speckles, curved petals, and visible stamens. The whole garden uses pink hues, including foliage, lights, and the night sky. Includes a replay button, mobile layouts, keyboard focus styles, and reduced-motion support.

Open `index.html` directly, or serve this folder with any static web server. No build step or dependencies are needed. `FLORES.html` opens the bouquet directly.

Edit `css/lilies.css` for the scene, `css/style.css` for the opening screen, and `img/pink-lily.svg` for the flower artwork. The original animation styles are in `css/main.css` and `scss/main.scss`; both contain the pink palette. The separate lily stylesheet should remain loaded after the animation stylesheet.
