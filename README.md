# animationsss

A pink lily animation that opens immediately, without a gift-opening screen or top dedication. Includes pink foliage, floating lights, a replay button, and reduced-motion support.

Public animation: https://joshmio42-cpu.github.io/animationsss/

Open `index.html` directly or use any static web server. No build step or dependencies are required. `FLORES.html` is an alternate entry point to the same animation.

Adapted from [gmpsankalpa/Flower-animation](https://github.com/gmpsankalpa/Flower-animation) and the [pink lily version](https://github.com/joshmio42-cpu/Flower-animation). The original MIT license and copyright are preserved in `LICENSE`.
